# C-Team handoff pack

This repository starter contains the agreed project context and spike instructions for handing C-Team to Codex.

Start by reading:

1. `PROJECT.md`
2. `SPIKE.md`
3. `AGENTS.md`
4. `.codex/agents/*.toml`
5. `KICKOFF.md`

Paste the contents of `KICKOFF.md` as the first prompt in the new Codex project.

The first milestone is deliberately limited to a console/protocol spike plus a minimal Codex plugin shell. The Apps SDK UI, SQLite persistence, analytics, and steering are deferred until the protocol and ChatGPT Desktop observation questions are answered.
